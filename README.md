# profAI — ИИ-профориентация (MVP веб-теста для взрослых)

Тест на профориентацию → персональный LLM-отчёт как веб-страница.
Полная продуктовая спецификация — в [`theoretical/`](theoretical/).

## Структура (монорепо, npm workspaces)

```
packages/shared   — общие типы и конфиг шкал (источник правды по ключам)
apps/api          — бэкенд: БД (Prisma), скоринг, LLM-оркестрация, очередь
apps/web          — фронтенд: прохождение теста + страница отчёта
```

## Стек

- **Backend:** Node.js + TypeScript, Prisma + PostgreSQL, Redis + BullMQ
- **Frontend:** React + TypeScript + Vite
- **LLM:** зарубежный провайдер (OpenAI/Anthropic) за адаптером; strict structured outputs

## Быстрый старт (Фаза 0)

```bash
cp .env.example .env          # заполнить DATABASE_URL и т.д.
npm install
npm run build:shared          # собрать общий пакет
npm run db:generate           # сгенерировать Prisma Client
npm run db:migrate            # применить миграции (нужен запущенный PostgreSQL)
npm run db:seed               # засеять 124 вопроса + 16 профессий
npm run test:api              # проверить банк вопросов
```

Тест `test:api` не требует БД — верифицирует транскрипцию банка вопросов
против конфига шкал.

## Фронтенд (Фаза 1)

```bash
npm run dev --workspace @profai/web    # дев-сервер на http://localhost:5173
```

Поток теста уже кликабелен: вступление → согласие → анкета → интервью →
закрытые блоки → экран ожидания → заглушка отчёта. Прогресс и автосохранение
(в localStorage) работают — при перезагрузке страница продолжает с места остановки.
Пока используется локальный клиент; когда поднимется PostgreSQL и API-сервер,
состояние переедет на бэкенд (сессии, автосейв по блокам), а экран отчёта (Фаза 4)
начнёт рендерить JSON от LLM-оркестратора.

## Дорожная карта

| Фаза | Содержание | Статус |
|---|---|---|
| 0 | Каркас монорепо, схема БД, сид вопросов и профессий | ✅ готово |
| 1 | Прохождение теста (сессии, автосейв, экраны, консент) | 🟡 фронт-поток готов (локальный клиент); API сессий ждёт PostgreSQL |
| 2 | Скоринг-движок + фильтр профессий + тесты | ✅ готово |
| 3 | LLM-оркестрация (draft_persona + final_report по секциям) | ✅ реальная модель (Sonnet 5) подключена |
| 4 | Страница отчёта (рендер всех секций) | ✅ готово (мок + живой API) |
| 5 | Консент-логи, наблюдаемость, e2e | ⏳ |

## ⚠️ 152-ФЗ

Тест собирает чувствительные ПД, которые уходят в зарубежный LLM. Обязательны:
явный консент (хранится в `TestSession.consentAt`), минимизация передаваемых
данных (в промпт — открытые ответы и агрегированные баллы, без лишних
идентификаторов), провайдер спрятан за адаптером для быстрой замены.
Отчёт маркируется как инструмент самопознания, не клиническая диагностика.
