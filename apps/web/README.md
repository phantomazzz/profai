# @profai/web

Фронтенд: прохождение теста + страница отчёта. Будет развёрнут в **Фазе 1**
(React + TypeScript + Vite). Порядок экранов — раздел 4 `product_context.md`:

вступление → анкета (7 полей) → открытое интервью (5) → RIASEC → 16 факторов
(×2 экрана) → Герчиков → Пинк → экран ожидания → страница отчёта.

Обязательные UX-требования: автосохранение после каждого блока, возобновление
незавершённой сессии, прогресс-бар, экран консента (152-ФЗ).
