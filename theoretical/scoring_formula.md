# Формула скоринга — взрослый тест

Все формулы детерминированные, без LLM — считаются на бэкенде мгновенно после отправки закрытых ответов.

## 1. Блок личностных черт (16 факторов) и мотивации (Герчиков)

Шкала ответа: 1-5 (Полностью не согласен → Полностью согласен).

**Шаг 1 — обработка реверс-вопросов.** Если вопрос помечен флагом `is_reverse = true`, его значение инвертируется перед суммированием:

```
adjusted_value = 6 - raw_value
```

Обычные вопросы используют `raw_value` как есть.

**Шаг 2 — сумма по фактору/типу.** Для фактора с N вопросами:

```
sum = Σ adjusted_value (по всем N вопросам фактора)
```

Диапазон суммы: от N (все ответы = 1) до 5×N (все ответы = 5).

**Шаг 3 — перевод в проценты (0-100%).**

```
percent = (sum - N) / (4 × N) × 100
```

Пример: фактор «Общительность», 5 вопросов, сумма ответов после инверсии реверс-вопроса = 19.
`percent = (19 - 5) / (4 × 5) × 100 = 14/20×100 = 70%`

Это применяется одинаково к каждому из 16 факторов личности (N=4 или 5 в зависимости от фактора) и к каждому из 5 типов мотивации Герчикова (N=4 для всех).

## 2. Блок интересов (RIASEC)

Шкала ответа: 1-4 (Совсем не моё → Точно моё), реверс-вопросов нет, N=5 вопросов на каждый из 6 типов.

**Абсолютный процент по типу:**

```
percent_absolute = (sum - N) / (3 × N) × 100
```

(диапазон суммы от N до 4N, поэтому делитель 3×N)

**Относительный вектор (для отображения профиля, как в примере референсного отчёта, где все 6 типов в сумме дают 100%):**

```
percent_relative[i] = percent_absolute[i] / Σ(percent_absolute по всем 6 типам) × 100
```

Верхние 2-3 типа по `percent_relative` формируют трёхбуквенный код Холланда (например, IEC), который используется дальше как основной ключ для фильтрации базы профессий.

## 3. Блок мотиваторов (Пинк: Автономия/Мастерство/Цель)

Шкала 1-5, реверс-вопросов нет, N=3 на каждый элемент.

```
percent = (sum - N) / (4 × N) × 100
```

## 4. Сводная таблица шкал после скоринга

Итог одной сессии — 27 числовых значений (0-100%):
- 16 факторов личности
- 6 типов RIASEC (относительный вектор)
- 5 типов мотивации Герчикова
- 3 показателя Пинка (Автономия/Мастерство/Цель) — не 27, а 30 итоговых значений, если считать их отдельно

Всё это сохраняется в таблицу `computed_scores` как пары (session_id, scale_key, percent) и передаётся в финальный промпт LLM как компактный JSON — не сырые 124 ответа, а именно эти ~30 итоговых чисел, что резко снижает токены на финальный вызов.

## 5. Фильтрация базы профессий (детерминированный этап перед LLM)

До вызова финального LLM бэкенд сам сужает базу профессий до 8-10 кандидатов по простому правилу:

1. Профессия имеет `riasec_code`, состоящий из 2-3 букв (например «IEC»). Совпадение хотя бы 2 из 3 букв с топ-3 буквами пользователя по `percent_relative` — профессия попадает в кандидаты.
2. Внутри отобранных кандидатов дополнительно сортируются по совпадению `trait_tags` профессии с топ-5 факторами личности пользователя (по абсолютному проценту) — чем больше пересечение, тем выше в списке.
3. Из топа берутся 5 для «подходящих» и 2-3 с наименьшим совпадением (но не нулевым — не случайные, а осмысленно «не то») для «неподходящих», чтобы LLM было из чего писать текст с реальным обоснованием, а не придумывать причины с нуля.

Только после этой фильтрации шорт-лист (не вся база) уходит в промпт финального вызова.
