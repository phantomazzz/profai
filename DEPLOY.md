# Деплой profAI (рабочий Sonnet 5)

## Почему не чистый Netlify, как в прошлый раз
Прошлая версия на Netlify была **демо** (`VITE_DEMO=1`) — статика с отчётом-образцом,
**без вызова LLM**. Настоящая генерация на Sonnet 5 — это бэкенд, который:
- держит секретный ключ (`LLM_API_KEY`);
- выполняет запрос **~2 минуты** (5 секций Sonnet);
- сохраняет отчёты для ссылок `/report/<slug>`.

Netlify — статика + serverless-функции с таймаутом ~10–26 с. 2-минутная генерация
там не выживает (и прокси Netlify к внешнему бэкенду тоже рвётся на ~26 с). Значит,
нужен **always-on Node-сервер**. Проще всего — один сервис отдаёт и API, и фронт.

## Вариант по умолчанию — Render (free), один сервис
Сервер (`apps/api/src/server.ts`) в проде отдаёт и `/api`, и собранный фронт
`apps/web/dist` с одного origin: без CORS, без прокси-таймаутов. Конфиг — `render.yaml`.

### Шаги
1. **Залить репозиторий на GitHub** (Render деплоит из git):
   ```bash
   git branch -M main
   git remote add origin https://github.com/<ты>/profai.git
   git push -u origin main
   ```
   (или `gh repo create profai --private --source=. --push`)
2. **Render → New → Blueprint** → подключить этот репозиторий. Render прочитает
   `render.yaml` и создаст free web service (build: `npm install --include=dev && npm run build`,
   start: `npm start`).
3. **Вписать секрет**: в сервисе → Environment → `LLM_API_KEY` = твой ключ Anthropic
   (в `render.yaml` он помечен `sync:false` и намеренно НЕ хранится в репо).
4. **Deploy** → через пару минут получишь URL вида `https://profai.onrender.com` —
   это и есть ссылка для тестеров. Полный флоу (тест → отчёт на Sonnet 5) работает.

### Что важно знать про free-план
- **Сон после ~15 мин простоя**: первый заход после паузы грузится ~30–60 с (холодный старт).
- **Эфемерный диск**: файловый стор отчётов сбрасывается при редеплое/перезапуске.
  Свой отчёт тестер видит сразу (кешируется в его браузере), а ссылка `/report/<slug>`
  живёт, пока инстанс не перезапустился. Для «показать паре знакомых» — ок; для
  постоянных ссылок позже нужен Postgres (таблица reports уже в схеме).
- **Стоимость**: ~$0.35–0.40 за сгенерированный отчёт (Anthropic, оплачивается с твоего ключа).
  На всякий случай поставь лимит трат в консоли Anthropic.

## Альтернативы
- **Railway / Fly.io** — тоже always-on Node; Railway без принудительного сна (есть месячный кредит),
  Fly требует карту. Тот же `npm run build` / `npm start`, порт из `PORT`.
- **Netlify только под фронт + бэкенд на Render** — рабочее, но сложнее: фронт должен
  звать бэкенд по абсолютному URL (не через прокси Netlify из-за таймаута), плюс CORS.
  Ради «отправить тест паре друзей» это лишнее — один сервис проще.

## Локальная проверка прод-сборки
```bash
npm run build
PORT=4177 LLM_PROVIDER=mock npm start   # откроется на http://localhost:4177 (мок, без трат)
```
`/`, `/report/<slug>` (SPA-фолбэк), `/health`, `/api/report` — всё с одного порта.
